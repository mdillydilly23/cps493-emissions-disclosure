# Raw data

1. Accept the Kaggle license for [Green Miles](https://www.kaggle.com/datasets/chaitanyajamble/green-milescorporate-logistics-and-carbon-emissions).
2. Download the dataset CSV and save as **`green_miles.csv`** in this folder.

If `green_miles.csv` is missing, scripts fall back to **`green_miles_sample.csv`** (10 rows) for smoke testing.
